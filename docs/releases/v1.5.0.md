# v1.5.0 — Herdr card-run workflow

The workflow can route an authorized parent task through the reusable local
`herdr-dispatch` skill. The controller splits execution cards, schedules
dependencies and resources, accepts deliveries, requests repairs, and completes
commit/PR/merge/archive/cleanup under the saved full-run authorization.

Optional contract review remains before implementation. Cards do not create
separate native Trellis tasks or hooks. Existing writable checks and once-per-PR
OCR remain in place. Single execute/review dispatch does not authorize full-run
closure. The skills stay locally managed in Skills Manager; this repository
distributes the workflow pointer and companion setup tools.

## Installation

After the immutable `v1.5.0` tag exists:

```bash
trellis init --yes --user <name> --codex \
  --workflow solo-github-flow \
  --workflow-source gh:kakamisamas/trellis-personal-marketplace#v1.5.0
```

Run the matching `v1.5.0/scripts/setup.sh` bootstrap for companion tools.
Card-run additionally requires `~/.skills-manager/skills/herdr-dispatch/SKILL.md`.
Ordinary Trellis tasks continue to work without that local skill.

## Validation and lineage

The candidate workflow is tested with Trellis 0.6.12 in CI and 0.6.16 locally.
This release builds on main after v1.4.0; no existing tag is moved. The separate
release/v1.4.1 branch has no published v1.4.1 tag and is not this release baseline.
