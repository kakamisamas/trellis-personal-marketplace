# v1.7.0 — CodeGraph removed; review triage rules

This release removes CodeGraph from the workflow and its tooling, and ships the
review triage rules merged after v1.6.1.

- CodeGraph support is gone. Measured on the projects that adopted it, agents
  never queried the index: zero MCP calls across 43 sessions, while every task
  worktree still paid for `prepare` and `sync`. The repositories are small
  enough that `rg` plus targeted reads stays cheaper than `codegraph explore`.
  Phase 1.0 no longer prepares a task-worktree index, the in-progress
  breadcrumbs no longer carry sync instructions, dispatch prompts no longer
  require a CodeGraph `projectPath`, and `setup.sh` no longer installs
  `scripts/trellis_codegraph.py`. CI dropped the CodeGraph integration job.
- The controller triages every contract-review finding and every rework
  `must_fix` (reject, adopt, accept risk, defer, or back to design, one-line
  reason each). A plan or reviewed object gets at most 3 review verdicts, and
  cumulative fix additions above the fix budget send the card back to design
  instead of another rework round.

## Downstream projects

Projects on v1.5.x or v1.6.x switch the workflow and rerun the installer from
this release. The installer does not delete files it no longer manages, so
remove these by hand in the same change:

- `scripts/trellis_codegraph.py`;
- the `.codegraph/` rule in `.gitignore` and any local `.codegraph/` index;
- `trellis-setup` skill copies that still list `scripts/trellis_codegraph.py`.
  `setup.sh` installs the skill only when it is absent and exits 2 when an
  existing copy differs; replace each differing copy with the v1.7.0 asset.

Projects that edited `.trellis/workflow.md` port their local edits onto the new
file instead of replacing it blindly.

## Installation

After the immutable `v1.7.0` tag exists:

```bash
trellis workflow \
  --marketplace gh:kakamisamas/trellis-personal-marketplace#v1.7.0 \
  --template solo-github-flow \
  --create-new
```

Review `.trellis/workflow.md.new` before switching. Run the matching
`v1.7.0/scripts/setup.sh` bootstrap for companion tools.

## Validation and lineage

This release builds on v1.6.1; no existing tag is moved. The candidate workflow
is tested with the repository unittest suite.
